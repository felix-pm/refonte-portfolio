# Portfolio (refonte) - Félix Parendeau Millerioux

Refonte de mon portfolio personnel : même contenu que la version précédente, avec une identité visuelle plus professionnelle, reprise de ma photo de profil et de ma bannière LinkedIn (marine, bleu ciel, grille de points).

## À propos

Étudiant en Bachelor Développeur FullStack à **CODA_ Orléans**, je suis à la recherche d'une alternance. Ce site présente mon parcours, mes compétences et les projets que j'ai réalisés, avec un accès rapide à mon CV.

## Technologies utilisées

Site réalisé en natif, sans framework ni étape de build :

* **HTML5** : structure sémantique, balises Open Graph et données structurées (schema.org).
* **CSS3** : variables (`:root`), Grid / Flexbox, design responsive (mobile, tablette, desktop), animations respectant `prefers-reduced-motion`.
* **JavaScript** : navigation active selon la section, apparition des blocs au défilement, copie de l'adresse e-mail.
* **Font Awesome** pour les icônes, **Schibsted Grotesk** et **JetBrains Mono** (Google Fonts) pour la typographie.

## Sections

* **Accueil** : présentation, coordonnées et téléchargement du CV.
* **À propos** : parcours et motivations.
* **Expériences et formations** : timeline des formations et des expériences professionnelles.
* **Compétences** : frontend, backend, base de données, langues et soft skills.
* **Projets** : RideTeam, Fair count, The League et deux sites vitrines.
* **Contact** : e-mail, LinkedIn, GitHub, téléphone et CV.

## Lancer en local

Aucune dépendance : ouvrir `index.html` dans un navigateur, ou servir le dossier :

```bash
python -m http.server 5500
```
